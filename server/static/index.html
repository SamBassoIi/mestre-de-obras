Como Rodar no Autodesk Inventor

Opção 1: Envio Direto via COM API (1 Clique)

Se o Autodesk Inventor estiver instalado no seu Windows, basta clicar no botão "Enviar para Autodesk Inventor (Direto)". O sistema conecta na sua sessão do Inventor e modela a peça com sketches e extrusões paramétricas em tempo real!

Opção 2: Regra iLogic Portável (.iLogicVb)

Para usar em qualquer máquina (laboratórios da faculdade, etc.):

  1. No Autodesk Inventor, abra uma nova peça métrica (Standard (mm).ipt).
  2. Vá na aba Manage (Gerenciar) > painel iLogic > clique em Add Rule (Adicionar Regra).
  3. Dê um nome para a regra (ex: ModelarAutoCroqui).
  4. Cole o código gerado pelo AutoCroqui3D e clique em Save & Run (Salvar e Executar).
  5. A peça será construída instantaneamente com todo o histórico de operações (features) na árvore!
